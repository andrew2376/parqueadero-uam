# Flujo de trabajo Git

- `main`: versiones estables.
- `develop`: integración.
- `feature/<id>-<descripcion>`: desarrollo de historias.
- `release/<version>`: preparación de entrega.
- `hotfix/<version>`: correcciones urgentes.

Crear ramas de funcionalidad desde `develop`, realizar commits pequeños, abrir Pull Request, revisar cambios y ejecutar pruebas antes de integrar. No subir `.env`, contraseñas ni claves privadas.
